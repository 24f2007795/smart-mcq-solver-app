# Smart MCQ Solver

A Streamlit application powered by a fine-tuned RoBERTa model for solving multiple-choice questions.

## Features

- Fine-tuned RoBERTa model
- Predicts Top-3 answer choices
- Displays confidence scores
- Simple Streamlit interface

## Kaggle Performance

Best Public Leaderboard Score: **0.75145**

## Tech Stack

- PyTorch
- Hugging Face Transformers
- Streamlit
